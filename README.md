# MoveIt

MoveIt is a full-stack logistics and delivery platform designed to make sending packages fast, simple, and reliable. Users can book deliveries, track shipments, and manage orders through a clean and responsive web interface, while administrators oversee deliveries and platform operations from a dedicated dashboard.

Built with the **MERN** stack, MoveIt focuses on providing a seamless experience for both customers and delivery personnel.

---

## 🚀 Features

- User registration and secure authentication
- Book package deliveries
- Real-time delivery tracking
- Delivery history and order management
- Responsive user interface
- Admin dashboard for managing deliveries
- RESTful API
- Secure JWT authentication

## 🚀 Getting Started

Open **two terminal windows**.

### Backend

```bash
cd server
npm install
cp .env.example .env

npm run dev
```

Runs on:

```
http://localhost:5000
```

### Frontend

```bash
cd client
npm install
cp .env.example .env

npm run dev
```

Runs on:

```
http://localhost:5173
```
